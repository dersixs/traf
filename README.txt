vertoxe — закрытый сайт команды (без сервера и установки)
==========================================================

КАК ОТКРЫТЬ
  Распакуйте архив и дважды кликните index.html. Работает без интернета, шрифты лежат в папке fonts.

КОДОВОЕ СЛОВО
  Сейчас: Welcome1144 (регистр не важен: welcome1144 тоже подойдёт).
  В файлах хранится только его хэш, не само слово.
  Как сменить: откройте change-code.html, введите новое слово, скопируйте хэш.
  Затем в index.html найдите  window.VX_KEY_HASH = "..."  и замените значение в кавычках.

ВАЖНО О ЗАЩИТЕ
  Вход работает в браузере. Он надёжно останавливает случайных посетителей, но тексты лежат
  в самом index.html, и технически подкованный человек может их найти через «исходный код страницы».
  Не размещайте на сайте ничего, что нельзя показать посторонним. Если нужна настоящая защита,
  включите парольную защиту на хостинге (Cloudflare Access, Netlify Password Protection и т.п.).

ГДЕ МЕНЯТЬ ТЕКСТЫ (все тексты в НАЧАЛЕ index.html, сразу после <body>, блоки <script type="text/plain">)
  Instagram мануал   блок  data-block="manual"      (вставьте весь мануал ОДНИМ текстом, заголовок не нужен)
  Материалы: «Что это такое»  блок data-block="about"   (весь текст одним куском)
  Как строятся выплаты блок data-block="payouts"    (весь текст одним куском, как и мануал)
  Что делать если    блоки data-section="faq"       (4 карточки: первая строка = вопрос, ниже = ответ)
  Хештеги            блок  data-block="hashtags"
  Список музыки      блок  data-block="music"       (одна строка = один трек)
  Ссылки и контакт   блок  data-block="links"
  Результат          блок  data-block="leaders"     (цифры и подписи к скриншотам)
  Чтобы добавить карточку «Что делать если», скопируйте блок целиком и вставьте под ним.
  Оглавление, время чтения и подзаголовки мануала собираются автоматически.
  Если в мануале нет «##», короткие строки-заголовки (без точки в конце, с пустой строкой до) становятся подзаголовками сами.

КАК ВСТАВИТЬ БОЛЬШОЙ МАНУАЛ (самый простой способ)
  1. Откройте в браузере файл paste-manual.html (лежит рядом с index.html). Работает и на телефоне.
  2. Шаг 1: выберите index.html. Шаг 2: оставьте «Instagram мануал».
  3. Шаг 3: вставьте весь текст в большое поле.
  4. Нажмите «Скачать index.html» и положите скачанный файл в папку сайта вместо старого.
  Тот же помощник вставляет текст в «Как строятся выплаты», хештеги и список музыки (выбор в шаге 2).

  Ручной способ: откройте index.html в текстовом редакторе, найдите (Ctrl+F) data-block="manual",
  удалите текст между <script ...> и </script> и вставьте свой. Теги <script> не трогайте. Сохраните файл.

  Можно выбрать готовый .txt файл вместо вставки.
  Оформление необязательно: заголовки (в т.ч. «1. Название», ЗАГЛАВНЫЕ, строки с эмодзи), «Что нужно:» перед списком,
  абзацы с ⚠️ или «Важно:» (красный блок) и с 📌 или «Совет:» (подсказка) сайт распознаёт сам.
  Оформление необязательно. Без «##» сайт сам найдёт короткие строки-заголовки,
  сделает оглавление, шаги из «1. 2. 3.», списки из «- » и кликабельные ссылки.

ОФОРМЛЕНИЕ ТЕКСТА В МАНУАЛЕ
  ## Подзаголовок        крупный подзаголовок (попадает в оглавление)
  ### Мелкий заголовок
  - пункт                маркированный список
  1. шаг                 нумерованные шаги (красивые карточки)
  > Подсказка            выделенный блок
  > ! Предупреждение     красный блок
  **жирный**             выделение
  [текст](https://...)   ссылка с названием; обычные https://... тоже кликабельны
  ---                    разделительная линия
  Пустая строка = новый абзац.

ССЫЛКИ И КОНТАКТ ВЛАДЕЛЬЦА (блок data-block="links")
  unique =     ссылка на сервис уникализации видео
  metadata =   ссылка на сервис удаления метаданных
  owner =      контакт владельца, например https://t.me/username или @username
  ownerName =  как показать контакт, например @username
  Пока ссылка пустая, на странице показывается «Ссылка скоро появится».

РЕЗУЛЬТАТ УЧАСТНИКА (блок data-block="leaders")
  period: / member: / title: / lead:   подписи
  kpi: значение | подпись              крупные цифры
  shot: assets/файл.jpg | заголовок | описание   скриншот (файлы лежат в папке assets)
  Первый shot показывается ПО ЦЕНТРУ (главный), остальные по бокам. Скриншоты открываются крупно по клику. Чтобы заменить, положите новый файл в assets и поправьте строку shot.

ЦВЕТА
  css/style.css, вверху блок :root. Акцент: --acid (#b6ff00), фон: --bg (#0a0a0a).

КАК ОПУБЛИКОВАТЬ
  Обычные статические файлы: Netlify Drop (app.netlify.com/drop), Cloudflare Pages, GitHub Pages.
  Главное, чтобы index.html лежал в корне.

СОСТАВ
  index.html        страница и ВСЕ тексты
  paste-manual.html помощник: вставляет большой текст в index.html без правки кода
  change-code.html  помощник для смены кодового слова
  css/              оформление и шрифты
  js/app.js         вход, разделы, поиск, копирование, просмотр скриншотов
  assets/           скриншоты результата и логотип (logo.svg, logo.png — для аватарки)
  fonts/            шрифты Onest и Oswald (лицензия SIL OFL)
